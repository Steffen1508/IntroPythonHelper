# Exam Prep Helper

Øveværktøj til den mundtlige eksamen i AI-Programmering (DAKI, 1. semester).

## Sådan lægges siden op med GitHub Pages

1. Upload alt indholdet af denne mappe til roden af et offentligt repository.
2. Gå til Settings, Pages, vælg "Deploy from a branch", branch `main` og mappen `/ (root)`.
3. Siden ligger derefter på `https://<brugernavn>.github.io/<repository>/`.

## Filer

- `index.html`: hele siden med spørgsmål, svar og kodeopgaver.
- `vendor/`: Skulpt 1.2.0, som kører Python i browseren (se https://skulpt.org).
- `.nojekyll`: får GitHub Pages til at servere filerne uændret.
